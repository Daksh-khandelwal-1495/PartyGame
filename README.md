# MyGame – Party Charades

A free Heads Up!-style party charades game built with React, TypeScript, and Capacitor.

## Features

- 🎮 **10 built-in deck categories** – Celebrities, Movies & TV, Animals, Countries, Music, Science & Tech, Sports, Video Games, Food, and Fantasy
- ✏️ **Custom deck creator** – Add your own word lists manually or via voice input
- 🎤 **Voice input** – Speak your words to build a deck hands-free
- ⏱️ **Configurable timer** – Choose 30, 45, 60, 90, or 120 second rounds
- 🔄 **Multi-round sessions** – Play 1–7 rounds per session
- 📱 **Tilt controls** – Tilt the phone forward to mark correct, backward to skip
- 🏆 **Achievements & stats** – Track games played, streaks, and unlock badges
- ♿ **Accessibility** – Large text and high-contrast mode

## Getting Started

```bash
npm install
npm run dev        # start development server
npm run build      # build for production
npx cap sync android  # sync to Android
```

## Tech Stack

- **React 18** + TypeScript
- **Vite** build tool
- **Capacitor** for native Android/iOS deployment
- **lucide-react** icons
